# Data Science Projects

Welcome! I'm **Kavin Somu**, an **M.S. in Analytics graduate student at Georgia Tech**.  
This repository showcases a collection of my **data science and analytics projects**, covering topics such as **machine learning, predictive modeling, simulation, and applied analytics** using real-world datasets.

---

## Featured Projects

| Project | Description | Key Techniques / Tools |
|----------|--------------|------------------------|
| [**Real vs. Fake News Detection**](./Fake-News-Detector) | Investigates whether machine learning models leveraging NLP and statistical features can effectively classify news articles as real or fake. Achieved **96.1% accuracy** and **0.993 AUC-ROC** using an ensemble stacking model. | Python, scikit-learn, TF-IDF, Logistic Regression, Naïve Bayes, NLP, Ensemble Modeling |
| [**Hotel Booking Cancellation Prediction**](./Hotel-Bookings) | Predicts hotel booking cancellations to help optimize overbooking strategies and improve occupancy rates. Compared Logistic Regression, Random Forest, and XGBoost using **5-fold cross-validation** for model tuning. | R, dplyr, ggplot2, randomForest, caret, XGBoost |
| [**Price Elasticity Regression Model**](./Price_Elasticity_Food_Prices) | Analyzes U.S. grocery price trends (2019–2023) and models how **income class influences price elasticity** for items like eggs, chicken, ice cream, and coffee. | R, Linear Regression, Interaction Terms, ggplot2, dplyr |
| [**Stock Options Simulation Project**](./Stock-Options-Simulation) | Compares **Monte Carlo** and **Binomial Tree simulations** for valuing European stock options against the Black-Scholes analytical model, showing that binomial simulation yields the most accurate pricing. | Python, NumPy, pandas, SciPy, Monte Carlo Simulation |
| [**Tennis Data Analysis – 2017 ATP Season**](./Tennis-Data-Analysis) | Analyzes ATP player performance across tournaments, exploring the effects of player country and height on success using match-level data from the 2017 season. | Python, pandas, matplotlib, seaborn, EDA |
| [**Zillow House Price Prediction – South Florida**](./Zillow-House-Prices-Prediction) | Builds machine learning models (MLR, Neural Network, Random Forest, Gradient Boosting) to **identify undervalued homes** using Zillow API data. Outputs ranked home lists sorted by undervaluation. | Python, scikit-learn, XGBoost, Neural Network, Regression, Feature Engineering |
