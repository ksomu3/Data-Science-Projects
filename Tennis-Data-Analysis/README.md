# Tennis Data Analysis – 2017 ATP Season

This project analyzes player performance during the **2017 Association of Tennis Professionals (ATP) season**.  
It explores:
- Results at the **Grand Slam** and **tournament** levels  
- The impact of **player country** and **height** on performance

## How to Open and Read
To explore the analysis:
1. Download the following files and keep them in the **same folder**:
   - `2017+ATP+Season Project.ipynb`
   - `match_scores_2017_unindexed_csv.csv`
   - `player_overviews_unindexed_csv.csv`
2. Open the notebook file (`2017+ATP+Season Project.ipynb`) in your preferred IDE,  
   such as **Jupyter Notebook**, **JupyterLab**, or **Visual Studio Code**.
3. Run or read through the cells to view the data analysis and visualizations.

## Requirements
The notebook uses common Python data-science packages (for example, `pandas`, `numpy`, `matplotlib`, `seaborn`).  
If these packages are not already installed, you can add them through your environment or IDE’s package manager.
